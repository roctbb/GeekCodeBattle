# Arena artwork

`temple.jpg` is the cinematic background developed for the CodeBattle concept in this chat with the built-in ImageGen tool. It is an opaque JPEG (1536×1024; approximately 352 KiB), bundled by Vite. The original generated PNG remains in the chat's generated-image directory.

Prompt direction: an ancient East Asian tournament temple at night; charcoal basalt and engraved bronze; a round dragon medallion; an amber fire warrior on the left and a navy/cyan ice warrior on the right; dark negative space in the centre; embers, mist and restrained cinematic lighting; no lettering, interface, watermark, weapons, blood or gore. The lobby and results use native CSS banners and pedestal geometry rather than repeating the hero scene.

The CodeBattle emblem is the original code-native SVG in `CodeBattleMark.vue`. Manrope fonts, including full-width Cyrillic headings at weight 700, are bundled from `@fontsource/manrope`; the license text is distributed in `public/licenses/`.
